# Flow Learning UI Overhaul Plan (Streams‑First)

## Цели
- Сделать динамику потоков «физически» понятной: траектория + длины шагов + углы.
- Упростить интерфейс: убрать неинформативные блоки (центр/таблица), дать больше ширины графикам.
- Показать «что хорошо/плохо» прямо в UI (направление улучшения, min/mean/max).
- Сохранить headless режим и минимальную нагрузку на обучение.

---

## 1) Новая схема компоновки
**Общий layout**
- Верх: большая полоса «динамика потоков» (3 дорожки).
- Справа вертикальная колонка графиков (Loss, Rates, Accuracy, Boundary).
- Слева компактная панель состояния (Quality + параметры).

**Что убираем**
- Центральный сегмент/круг (низкая информативность).
- Таблицы чисел для потоков.

---

## 2) Новый виджет “Stream Track”
**Идея**
Каждый поток — горизонтальная дорожка из отрезков (по шагам).

**Отрезки**
- Длина сегмента = скорость/модуль шага (масштаб × kSpeedScale).
- Наклон = угол направления (масштаб × kAngleScale).
- Цвет сегмента = поток (0/1/2).
- Спайк = красная метка/подсветка сегмента.

**Граница**
- Отдельная дуга/полудуга над дорожкой показывает «круговую границу».
- Пунктирная линия от сегмента до дуги = проекция.
- Отметка «дошёл/не дошёл» = пересечение/маркер на дуге.

**Точки/метки**
- Вместо таблицы: метки значений в ключевых точках (step 0 / mid / end / spike).
  - r (radius), v (speed), E (energy), bin.
- Метки маленькие, полупрозрачные, цвет совпадает с типом.

---

## 3) Графики справа (stacked column)
**Новая компоновка**
- Вертикальная колонка графиков справа.
- Каждый график — широкий горизонтальный sparkline + min/mean/max.

**Loss**
- Четыре линии/канала: total, bins, negative, boundary.
- Подпись направления: “↓ better”.

**Rates**
- Spike rate, Completion, Radial miss.
- Подпись: “target = …”, “↓ better/↑ better”.

**Accuracy**
- Option accuracy отображать как «mean over window», не только 0/1.
- Подпись: “↑ better”, рядом %.  

**Histogram (output vs target)**
- Output (green) = полупрозрачный fill.
- Target (blue) = плотный контур/колонка под ним.

---

## 4) Легенда и подсказки
- В одном месте (вверху динамики):
  - Легенда: boundary arc, projection, spike, segment.
  - Маленький блок «Good/Bad» с примерами.
- В каждом графике: подпись направления улучшения.
